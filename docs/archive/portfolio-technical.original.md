# Project Technical Context

This project is a personal portfolio website built using **Rust and Yew**, a modern, component-based frontend framework that compiles to WebAssembly (WASM).

## Technology Stack

- **Language:** Rust
- **Frontend Framework:** Yew
- **Compilation Target:** WebAssembly (WASM)
- **Build Tool:** Trunk
- **Routing:** Yew Router
- **Styling:** CSS / Tailwind CSS
- **Package Manager:** Cargo
- **Deployment:** Static hosting (GitHub Pages)

## Development Guidelines

- Use Yew functional components and hooks, following modern Rust development practices.
- Follow a modular, reusable, component-based architecture similar to React.
- Use Rust for frontend application logic instead of JavaScript or TypeScript whenever practical.
- Prioritize performance, lightweight dependencies, maintainability, and responsive design.
- Keep the website fully static, without requiring a backend server.
- Optimize WebAssembly bundle size and initial loading performance.
- Maintain clean code organization and separation of concerns.
- Use Trunk for local development and production builds.
